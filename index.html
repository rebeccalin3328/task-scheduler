Task Scheduler

Find it in Google Calendar on a computer: Settings → your team calendar → Integrate calendar → Calendar ID. Leave empty to use your own calendar.

Add to team calendar Open in Calendar app instead

How to use
  1. In WhatsApp, long-press a message → ⋮ (top right) → Copy. Tip: select several messages first to copy them together.
  2. Open Task Scheduler and tap Paste copied message. If Chrome asks to see copied text, tap Allow.
  3. Check the task, date and time. Fix anything that looks wrong.
  4. Tap Add to team calendar, then Save in Google Calendar.
