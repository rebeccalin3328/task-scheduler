How to use
  1. In WhatsApp, long-press a message → ⋮ (top right) → Copy. Tip: select two or more messages before copying, so the sender's name or number comes along too.
  2. From email (Gmail, Outlook): select the text, including the From and Subject lines if you can, then tap Copy. The subject becomes the task, and the sender becomes the contact.
  3. Open Task Scheduler and tap Paste copied text. If Chrome asks to see copied text, tap Allow.
  4. Check the task, date and time. Fix anything that looks wrong.
  5. Tap Add to team calendar, then Save in Google Calendar.
